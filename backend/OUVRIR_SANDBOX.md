# 📧 Ouvrir My Sandbox

## ✅ Tu es au bon endroit !

Tu vois :
```
My Sandbox
0 messages
Empty
```

## 📍 Action immédiate

**Clique sur "My Sandbox"** (le nom de la sandbox)

Cela va ouvrir la page de la sandbox où tu verras :
- Les messages reçus (vide pour l'instant)
- Les onglets : **Messages**, **SMTP Settings**, **API**

## 🔑 Prochaine étape

Une fois dans "My Sandbox", clique sur l'onglet **"SMTP Settings"**

Tu verras alors :
- Les credentials SMTP
- Une liste de frameworks (Laravel, Symfony, etc.)
- **Sélectionne "Laravel"**
- Copie les 4 valeurs : Host, Port, Username, Password

---

**Clique sur "My Sandbox" maintenant !** 🚀
