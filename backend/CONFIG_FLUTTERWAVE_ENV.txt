===========================================
IMPORTANT
===========================================

1. FLUTTERWAVE_SECRET_KEY :
   - Clé secrète de test (déjà remplie)
   - Ne la partage JAMAIS

2. FLUTTERWAVE_PUBLIC_KEY :
   - Clé publique de test (déjà remplie)
   - Peut être utilisée côté client (mais pas nécessaire ici)

3. FLUTTERWAVE_WEBHOOK_SECRET :
   - Laisse vide pour l'instant (optionnel pour les tests)
   - Tu le configureras plus tard si besoin

4. FLUTTERWAVE_BASE_URL :
   - URL de l'API Flutterwave (déjà remplie)
   - Ne change pas cette valeur

===========================================
APRÈS CONFIGURATION
===========================================

1. Sauvegarde le .env

2. Vide le cache Laravel :
   php artisan config:clear

3. Teste le système :
   - Va dans Dashboard > Mon Abonnement
   - Choisis un plan
   - Clique sur "S'abonner avec ma carte Visa"
   - Utilise une carte de test Flutterwave
