# 🔑 Créer un App Password Google

## ✅ Tu es au bon endroit !

Tu vois le formulaire :
```
Nom de l'appli
[Champ vide]
```

## 📝 Action immédiate

### Dans le champ "Nom de l'appli", écris :

**`Voicy Assistant`** ou **`Laravel Mail`** ou **`SMTP`**

(Ce nom est juste pour t'aider à identifier le mot de passe plus tard, tu peux mettre ce que tu veux)

### Puis clique sur **"Générer"** ou **"Créer"**

---

## 🔑 Ce qui va se passer

1. Google va générer un **mot de passe de 16 caractères**
2. Il sera affiché **une seule fois**
3. **Copie-le immédiatement** (exemple : `abcd efgh ijkl mnop`)

---

## ⚠️ Important

- **Copie le mot de passe maintenant** (tu ne pourras plus le voir après)
- **Enlève les espaces** quand tu le colleras dans le `.env`
- Exemple : `abcd efgh ijkl mnop` → `abcdefghijklmnop` dans le `.env`

---

## 📋 Après avoir copié le mot de passe

Donne-moi :
1. Ton **email Gmail** (ex: `barryyoussouf400@gmail.com`)
2. L'**App Password** que tu viens de créer (16 caractères)

Et je t'aide à le configurer dans le `.env` ! 🚀

---

**Écris "Voicy Assistant" dans le champ et clique sur "Générer" !** 🔑
